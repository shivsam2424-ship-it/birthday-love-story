# Birthday Love Story

A romantic birthday website built with React + Vite + Tailwind.

## Quick start

```bash
npm install
npm run dev
```

Then open the local Vite URL in the browser.

## Personalize it

Edit the content in `src/App.jsx`.

- Change her name: update the text in the welcome and finale sections.
- Change your name: update the personalized text in the message blocks.
- Add your real photos: replace the sample image URLs in `memories`.
- Add your own song: replace the Spotify embed URL in the floating music player.

## Notes

- This is designed to feel emotional, dreamy, and romantic.
- It is responsive for mobile, tablet, and desktop.
- The page flow includes the welcome, birthday wish, memory gallery, reasons, love letter, and final surprise.
